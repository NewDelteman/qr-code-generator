# qr-code-generator

Генератор QR-кодов на Python для Windows. Работает локально, без интернета и регистрации.

## Что умеет

- кодировать ссылку, обычный текст или контакт (vCard 3.0);
- задавать размер картинки в пикселях;
- выбирать цвет модулей и фона, с проверкой контраста;
- выбирать форму: квадрат, круг, сердце;
- сохранять результат в `qr.png` рядом с программой.

## Запуск

```
python -m pip install "qrcode[pil]"
python qr_link.py
```

Программа спросит, что кодируем, затем размер, цвета и форму. Готовый файл появится в папке со скриптом.

## Требования

- Python 3.12;
- библиотеки `qrcode` и `Pillow`.
